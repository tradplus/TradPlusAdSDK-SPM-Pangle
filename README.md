# TradPlus Pangle Adapter Swift Package

Swift Package Manager support for the TradPlus Pangle adapter (15.13.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Pangle.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Pangle.git", exact: "15.13.0")
```

Third-party dependency: Pangle Global `8.1.1-release.1`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.13.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
